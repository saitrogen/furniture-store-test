## How to Use

1. **Click any link** to view the design screenshot
2. **Use DevTools** (F12) to inspect elements and extract CSS
3. **Reference the README.md** for implementation guidance
4. **Extract colors, spacing, components** as listed in README

Each screenshot shows exact layout, spacing, colors, and typography for that screen.
